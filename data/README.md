# Data Sources

This directory contains documentation and references for the datasets used by the AIHire project.

## Datasets

The project uses or references the following datasets:

1. Resume Dataset
2. Job Description Dataset
3. Mozilla Common Voice Dataset
4. RAVDESS Emotional Speech Dataset
5. CodeSearchNet Dataset

## Data Usage

Dataset source references will be maintained in this file.

The actual datasets will not be uploaded to this repository when their size, license, or usage restrictions do not permit redistribution.

Credentials, API keys, passwords, and confidential institutional data must never be uploaded to this directory or repository.
