## Abstract

AIHire: Virtual Interview Platform is an AI-powered recruitment and candidate assessment platform designed to automate the initial stages of the hiring process.

The system analyzes a candidate's resume and compares it with the job description to perform resume shortlisting. Shortlisted candidates attend an AI-based voice interview where domain-specific technical questions are generated based on the candidate's resume and job requirements.

Candidate responses are converted into text using the Whisper Speech-to-Text model and evaluated using Transformer-based language models such as BERT and Sentence Transformers. The platform also performs speech emotion analysis and communication assessment to estimate confidence and speaking quality.

A short domain-specific coding assessment is conducted at the end of the interview. Finally, the system generates an AI-based evaluation report containing resume matching score, technical performance, communication score, coding score, confidence analysis, and an overall hiring recommendation for HR.

The project aims to provide a faster, structured, and intelligent approach to the initial recruitment process.
